Custom background music
========================

Drop your music file in this folder. The game looks for (in order):

  bgm.mp3
  bgm.ogg
  bgm.wav
  music.mp3 / music.ogg
  music.wav
  background.mp3 / background.ogg

Or any .mp3 / .ogg / .wav whose filename contains "bgm", "music", or "background".

Recommended: bgm.ogg or bgm.mp3 (looping arcade track works best).

If no file is found, built-in chiptune music plays instead.

After adding or changing a file, restart the game (or start a new match).
