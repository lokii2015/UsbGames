How to use UsbGames

Put games on a USB stick and play on any Windows PC. No account. Nothing installs on the computer — everything stays on the USB.

  1. Step 1 — Get a USB drive and the launcher. Use any USB stick. On this site, click Download Launcher (or go to Download). Save the ZIP file to your computer.
  2. Step 2 — Put the launcher on the USB. Unzip the file. Copy the whole UsbGames folder onto your USB. Inside you should see UsbGames.exe and a folder called PortableGames. Free games may already be in PortableGames.
  3. Step 3 — Add more games (optional). Free games: download a ZIP, unzip it, and drop the game folder into UsbGames\PortableGames\ on the USB (keep the folder name, e.g. Snake). Paid games: buy on the Store, download the ZIP after checkout, then unzip into PortableGames the same way.
  4. Step 4 — Play. Plug the USB into a Windows PC. Open UsbGames\UsbGames.exe. You’ll see your game list. Click a game to start it. You can unplug the USB and use it on another PC anytime.

Quick tips

  • Each game is its own folder inside PortableGames — don’t mix files between games.
  • After adding a game, click Refresh in the launcher if it doesn’t show up right away.
  • No internet needed to play once games are on the USB.
