PayPal SANDBOX — you CANNOT use your real PayPal account
========================================================

Sandbox (PAYPAL_MODE=sandbox) and Live are TWO SEPARATE WORLDS:
  - Sandbox checkout → sandbox.paypal.com → fake money only
  - Your REAL PayPal (personal + paypal.me) → LIVE only (PAYPAL_MODE=live + Live API keys)

You cannot pay sandbox with a real account, or pay live with a sandbox buyer.
That is how PayPal works — not a bug in this site.

To test WITHOUT your real account:
  1. Pay with test card (below), OR
  2. Log in with a Personal sandbox buyer from Developer Dashboard, OR
  3. Store → Paid Game ($0) → free order (no PayPal)

To take REAL money with YOUR personal PayPal + paypal.me:
  - Developer Dashboard → Apps → Live tab → Live Client ID + Secret
  - checkout/.env: PAYPAL_MODE=live
  - Deploy API to Render; test on Netlify with /api proxy

DO NOT PUT THESE IN checkout/.env (UsbGames does not use them):
  - NVP/SOAP Username (sb-xxxx_api1.business.example.com)
  - NVP Password
  - NVP Signature
Those are for old PayPal APIs. This site uses REST only:
  PAYPAL_CLIENT_ID + PAYPAL_CLIENT_SECRET from
  https://developer.paypal.com/dashboard/applications (Sandbox tab)

PAYPAL_ME_USERNAME is only your live paypal.me name (e.g. EthanCiuffreda),
NOT a sandbox @business.example.com email.

You must NOT use your real PayPal email/password in the popup when PAYPAL_MODE=sandbox.

USE A FAKE SANDBOX BUYER
------------------------
1. https://developer.paypal.com/dashboard/accounts
   (or Testing Tools → Sandbox accounts)

2. Under "Sandbox" find a **Personal** account (buyer), not Business.

3. Click the account → you will see:
   - Email (looks like sb-xxxx@personal.example.com)
   - Password → click "..." or menu → **Change password** / view password
   Set a simple password you remember (e.g. Test1234!)

4. On checkout, when PayPal opens:
   - Log in with THAT sandbox email + THAT password only
   - Or click "Log in with a sandbox account" if you see it

Set password → use that in the popup
